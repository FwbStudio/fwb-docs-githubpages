# Shoes Robbery — Commands

`fs_shoesrobbery` provides a command for law enforcement and staff to reset store robberies.

---

## Admin & Police Commands

::: details /resetshoesrobbery
Resets all robbed shoe stores on the server back to full stock and removes active robbery cooldowns.

### Syntax
```
/resetshoesrobbery
```

### Required Permissions
Configured in `config.resetcommand.permission`:
* **Admin Groups**: `admin`, `mod`
* **Job Groups**: `police` (Rank 3 or higher)
* Optional ACE or Identifier whitelisting.
:::
