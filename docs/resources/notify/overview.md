# Notify

### 🔔 Notify – Your Server's Notification Hub

Replace scattered notification styles with one polished, configurable notify system. FWB Notify gives server owners a shared panel to design alerts and gives developers clean exports to trigger them from any script.

Standalone — does **not** require FS Bridge.

#### ⚙️ Key Features

* **In-Game Notify Panel** — Open the editor with a command and preview styles live.
* **Client & Server Exports** — Trigger notifications from any resource with a consistent API.
* **Admin Permissions** — Lock the shared panel behind ACE permissions or let players customize.
* **Bridge-Friendly** — Works alongside FWB Bridge scripts that call the notify exports.
* **Lightweight Install** — No framework dependency; drop in and wire up your UI flow.

* Servers tired of mismatched alert styles
