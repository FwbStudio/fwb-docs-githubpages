# Duty System

### 👮 Duty System – Clock In, Clock Out

Give every whitelisted job a clean on-duty and off-duty flow that actually matters. Duty System tracks who is working, syncs with your framework job state, and exposes exports so MDTs, dispatch, and custom scripts can react in real time.

Works with **ESX**, **QBCore**, and **Qbox** through FS Bridge.

#### ⚙️ Key Features

* **On/Off Duty Toggle** — Simple duty switching for police, EMS, mechanics, and any job you configure.
* **Framework Sync** — Keeps duty status aligned with your active framework job data.
* **Client & Server Exports** — Query duty state, force on/off duty, or toggle from external resources.
* **Configurable Jobs** — Whitelist which jobs use the duty system and how they behave.
* **Bridge Integration** — Plays nicely with FWB Bridge for notifications, target, and inventory hooks.

#### 💼 Perfect For:

* Police and EMS departments
* Mechanic and service-job businesses
* Servers running custom MDT or dispatch tools
* Staff teams that need reliable duty tracking
* Any whitelisted job that should only work while on shift
