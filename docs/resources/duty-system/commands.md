# Duty System — Commands

Duty System includes admin commands for managing player duty statuses across the server.

---

### `/dutymenu`

Opens the admin duty management menu.

* **Command:** `/dutymenu`
* **Access:** Configurable in `fs_dutysystem/config/Config.lua` under `config.Admin.permission` (allowed by admin group, ACE permission, identifier, or character ID).
* **Description:** Opens an in-game administrative menu to view active duty rosters and manage on-duty / off-duty states for players across all whitelisted departments.
