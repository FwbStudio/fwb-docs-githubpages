# Switch — Commands

`fs_switch` provides a chat command to detach installed switches from your currently equipped weapon.

---

## Player Commands

::: details /r_switch
Detaches the switch attachment from the currently equipped full-auto weapon and reverts it back into its standard semi-automatic base version.

### Syntax
```
/r_switch
```

* **Usage**: Hold the switched weapon in your hands and execute `/r_switch`.
* **Result**: The weapon reverts to its base model, and if durability remains on the switch, the item is returned to your inventory.
:::
