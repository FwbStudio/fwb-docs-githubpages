# Clothing As Item

### 👕 Clothing As Item – Rob, Wear, and Exchange Apparel as Inventory Items

Turn apparel, chains, hats, masks, shoes, and full outfits into real tradeable items inside player inventories. Clothing As Item provides a complete clothing robbery & equipping system with configurable skill checks, hands-up requirements, and item presets.

Works with **ESX**, **QBCore**, and **Qbox** through FS Bridge.

#### ⚙️ Key Features

* **Apparel as Items** — Wear and remove chains, watches, hats, glasses, masks, vests, torsos, pants, shoes, and outfits directly from inventory.
* **Clothing Robberies** — Execute robbery commands (`/robchain`, `/robhat`, `/robmask`, `/robshoes`, `/roboutfit`, etc.) with skill check minigames.
* **Hands-Up & Dead Requirements** — Configurable target restrictions requiring targets to have their hands up or be incapacitated before robbing.
* **Preset Configurations (`config/preset/`)** — Individual preset files for 13 clothing categories with male/female variations and access whitelists.
* **Skill Check Minigames** — Built-in `ox_lib` skill checks for robbery interactions.
