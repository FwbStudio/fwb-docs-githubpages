# Wig Craft & Sell — Commands

`fs_weavewear` provides a chat command option for accessing the Weave & Wear business phone when item-based opening is disabled.

---

## Player Commands

::: details /wwphone
Opens the Weave & Wear Business Phone to access the **Buyers App** (Street Customers) and **Delivery App** (Wholesale Routes).

### Syntax
```
/wwphone
```

* **Requirement**: Enable command mode in `config/config.lua`:
  ```lua
  config.selling.phone.command.enable = true
  ```
:::
