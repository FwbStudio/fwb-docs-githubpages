# Advanced Crafting Tables — Commands

| Command / interaction | Purpose |
| --- | --- |
| `/fs_craftingtables` | Open the admin tablet; permission required |
| Open Table | Open a station's crafting menu |
| Open Tablet | Open that station's player handbook |

The command above is the default; Settings can change the admin command. Placement and tablet-calibration development commands are not included.

## Player controls

- Select a recipe to inspect required materials and output.
- Use the quantity controls when multi-crafting is enabled.
- Press **Enter** or select **Enter** to start crafting.
- Press **Escape** to close the current popup first, then the menu.
- With built-in progress, **Backspace** cancels the current craft. Completed entries in a sequential queue remain completed.
