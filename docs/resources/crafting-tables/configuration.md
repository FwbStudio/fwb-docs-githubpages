# Advanced Crafting Tables — Configuration

## In-game configuration

Open `/fs_craftingtables` and use these pages. Save changes before closing.

| Page | What you configure |
| --- | --- |
| Stations | Station names, types, placement, access and recipes |
| Progression | XP and level progression settings |
| DarkTube | Tutorial videos for the player handbook |
| Bridge | Framework, inventory, notification and target provider selection |
| Players | Player information and progression management |
| Logging | Logging provider and settings |
| Settings | Language, theme, debug, multi-crafting and other resource settings |

Station IDs are generated by the editor. Use a readable station label so players can recognize the table.

## Recipes

Set the reward item and quantity, required materials, kept tools, XP, required level, and duration. Weapon recipes can set starting durability and repair requirements. Item workbench recipes use a minimum of **20 seconds**; longer durations extend the mechanic work after the clipboard stage.

A kept tool must be present but is not consumed. Reward quantity is the output per craft. Multi-crafting scales the requested crafts according to the selected mode.

## Access

A station can be public or limited to selected players, jobs/grades or gangs. Recipe access is limited by the parent station: it cannot grant someone access to a station they cannot use. The recipe editor uses the station's available access choices.

XP belongs to the player at that individual station. Gaining XP at one station does not level up another station.

### Progress bar

In `bridge/default/progress.lua`, choose `builtin`, `ox_lib`, `qb-progressbar` or `custom`. The default is `builtin`. Missing optional providers fall back to the built-in bar.

```lua
FSBridge.Progress = {
    provider = 'builtin',
    custom = nil,
    cancel = nil,
}
```

For a custom provider, the `custom(options)` function waits until finished and returns true for completion or false for cancellation. Use `cancel` to close your custom UI when crafting aborts.

### Tablet position

Edit the matching entry in `bridge/default/tablets.lua`. `x`, `y`, `z` are local offsets in metres; `rx`, `ry`, `rz` are rotation angles in degrees. Restart after editing. No tablet-offset command is included in the release.

### Version status

Green means up to date. Yellow shows the installed and available versions. Failed or disabled checks are shown separately. The server checks once per resource start. Renaming the resource prints a warning every three seconds until you restore the name and restart.
