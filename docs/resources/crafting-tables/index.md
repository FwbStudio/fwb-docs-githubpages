The showcase video will be added here. Until then, explore the five interface previews below. Screenshots use the actual resource UI with sample data; recipes and materials are configurable.

## Weapon table

Select weapon recipes, check materials, review durability and start crafting at the lathe.

![Weapon crafting table interface](/images/crafting-tables/weapon-table.png)

## Attachment table

The milling machine provides a dedicated attachment crafting menu.

![Attachment crafting table interface](/images/crafting-tables/attachment-table.png)

## Item table

Use the workbench for item recipes, with the clipboard and mechanic work sequence.

![Item crafting table interface](/images/crafting-tables/item-table.png)

## Admin panel

Create stations, configure recipes and access rules, and manage settings from one tablet.

![Advanced Crafting Tables station administration](/images/crafting-tables/admin-panel.png)

## Player tablet

Each station has its own handbook, showing that player's progression and recipe unlocks.

![Player tablet progression and recipe information](/images/crafting-tables/player-tablet.png)
