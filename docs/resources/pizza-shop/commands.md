# Pizza Shop — Commands

Pizza Shop provides in-game chat commands for employees and authorized staff to interact with the shop management system and workplace options.

---

### `/fs_pizzashop`

Opens the main Pizza Shop interaction and workplace menu.

* **Command:** `/fs_pizzashop`
* **Access:** Restricted based on job, admin group, or player identifier permissions configured in `config.lua`.
* **Description:** Opens the main interaction menu for employees to access pizza ovens, preparation stations, inventory storage, and customer billing interfaces.
