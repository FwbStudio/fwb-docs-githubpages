# Burger Shop — Commands

Burger Shop provides in-game chat commands for employees and authorized staff to interact with the shop management system and workplace options.

---

### `/fs_burgershop`

Opens the main Burger Shop interaction and workplace menu.

* **Command:** `/fs_burgershop`
* **Access:** Restricted based on job, admin group, or player identifier permissions configured in `config.lua`.
* **Description:** Opens the main interaction menu for employees to access food preparation counters, workplace stations, inventory storage, and customer billing interfaces.
