# Tranquilizer — Commands

`fs_tranquilizer` provides an administrative chat command to open the live in-game management interface.

---

## Admin Commands

::: details /fs_tranquilizer
Opens the Tranquilizer administration and configuration dashboard.

### Syntax
```
/fs_tranquilizer
```

### Required Permissions
Requires the `fs_tranquilizer.admin` ACE permission or server administrative group rank.

### Features inside Menu:
* Adjust tranquilizer sedation duration and intensity.
* Configure persistent database timers for combat logging.
* Setup hospital recovery bed coordinates and orientation angles.
* Select target engine (`ox_target`, `qb-target`) and notification providers.
:::
