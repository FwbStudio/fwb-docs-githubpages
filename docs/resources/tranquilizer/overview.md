# Tranquilizer

### 💉 Tranquilizer – Non-Lethal Takedowns

Equip your server with tranquilizer darts, rifles, and sedative RP — complete with an in-game config UI that syncs live to all players. Tranquilizer is built for animal control, EMS scenarios, and police non-lethal arrests.

Supports **ESX**, **QBCore**, and **Qbox** via FS Bridge.

#### ⚙️ Key Features

* **Tranquilizer Weapons** — Configurable dart guns and sedative items with timed effects.
* **In-Game Config UI** — Open `/fs_tranquilizer` to edit timers, hospitals, and permissions live.
* **Live Sync** — Changes apply to all players without restarting the resource.
* **Hospital & Recovery** — Send sedated players to configured hospital coords for wake-up RP.
* **Admin ACE Setup** — Copy permission lines from the UI straight into your server.cfg.
