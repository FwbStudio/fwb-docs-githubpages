# Skitz Shoes Store — Commands

`fs_skitz` provides a chat command option for accessing the Skitz business phone when item-based opening is disabled.

---

## Player Commands

::: details /shoesphone
Opens the Skitz Business Phone to access the **Buyers App** (NPC Street Sales) and **Delivery App** (Wholesale Drops).

### Syntax
```
/shoesphone
```

* **Requirement**: Enable command mode in `config/config.lua`:
  ```lua
  config.selling.phone.command.enable = true
  ```
:::
