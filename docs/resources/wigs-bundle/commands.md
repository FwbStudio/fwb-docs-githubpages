# WigsBundle Business — Commands

`fs_wigsbundles` provides business management options through both in-world interaction points and optional chat commands.

---

## Player & Staff Commands

::: details /wigsphone
Opens the Wigs Business Phone for street customers and delivery orders.

### Syntax
```
/wigsphone
```

* **Usage**: Can be configured in `config.restriction.phone` or used via the inventory item.
:::
