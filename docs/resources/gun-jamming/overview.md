# Gun Jamming

### 🔫 Gun Jamming – When Firepower Fails

Add tension to every shootout with a realistic weapon jamming system. Guns can fail mid-fight, forcing players to clear the jam or adapt — while whitelisted jobs like police stay reliable when you want them to.

Works with **ESX**, **QBCore**, and **Qbox** through FS Bridge.

#### ⚙️ Key Features

* **Per-Weapon Jam Chance** — Set jam and unjam odds individually for pistols, rifles, and custom weapons.
* **Job Whitelist** — Exempt police, sheriff, or any job from jamming entirely.
* **Unjam Behavior** — Choose whether players can shoot while clearing a jam or must stand still.
* **Custom Notifications** — Branded alerts when a weapon jams or is cleared.
* **Lightweight Config** — Tune everything from a single config file with no bloat.
