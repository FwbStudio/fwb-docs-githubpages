### 💳 Fraud System – Scam Your Way to the Top

Run a full underground fraud operation on your FiveM server with placeable gear, cloned cards, forged documents, and shady shops. Fraud System v1 is the classic FWB fraud stack — perfect for servers that want a proven criminal economy without the expanded v2 item set.

Supports **ESX**, **QBCore**, and **Qbox** via FS Bridge.

#### ⚙️ Key Features

* **Placeable Equipment** — Set up laptops, printers, skimmers, and generators anywhere on the map.
* **Card Cloning & Forgery** — Clone cards, print slips, and forge cheques through multi-step RP.
* **Generator Power** — Fuel-based generators keep your scam setup running with configurable consumption.
* **Black-Market Shops** — Sell tools and buy stolen data from configurable NPC vendors.
* **Job Restrictions** — Optionally lock the entire system to a scammer job or gang role.
