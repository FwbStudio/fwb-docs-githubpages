# Safezone Creator — Configuration

Edit the config files inside `fs_safezonecreator/config/`. Exact keys depend on your package version.

## Config excerpt

```lua
--[[

    --------------------------------------------------------------------------
      FS SAFEZONE CREATOR
    --------------------------------------------------------------------------

      This resource is configured in-game.

      Open the admin panel with:

          /safezonemenu

      Safezones, permissions, bridge providers, logs, notifications,
      creation tool settings, icons, blips, and debug options are all managed
      from that menu.

      This file is intentionally left as a clean note so server owners know
      where to configure the resource without editing Lua files.

    --------------------------------------------------------------------------

]]
```
