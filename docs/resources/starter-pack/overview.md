# Starter Pack

### 🎁 Starter Pack – Welcome New Players Right

Give every new character a proper welcome with configurable starter rewards, daily login streaks, and gendered payout tables. Starter Pack handles cash, items, vehicles, and black-money conversion across ESX, QBCore, and Qbox.

Works with **ESX**, **QBCore**, and **Qbox** through FS Bridge.

#### ⚙️ Key Features

* **Starter Rewards** — One-time packs with money, items, and vehicles per gender or character model.
* **Daily Reward Streaks** — Consecutive login bonuses with milestone rewards and optional whitelists.
* **NPC Claim Points** — Configurable ped locations with blips, animations, and vehicle spawn spots.
* **Black Money Handling** — Auto-converts dirty-money rewards for QBCore and Qbox item setups.
* **Bridge Auto-Detect** — Framework, inventory, target, and vehicle-key bridges detected automatically.

#### 💼 Perfect For:

* New-player onboarding
* Servers wanting structured daily logins
* Economy servers with gentle starter boosts
* Whitelist communities with curated rewards
* Owners replacing messy manual starter commands
