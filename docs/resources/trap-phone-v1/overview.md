# Trap Phone v1

### 📱 Trap Phone – Street Deals from Your Pocket

Run a burner-phone drug operation where players receive calls, meet buyers, and move product across the map. Trap Phone v1 is the original FWB street-dealing system — lean, proven, and built for classic trap RP.

Supports **ESX**, **QBCore**, and **Qbox** via FS Bridge.

#### ⚙️ Key Features

* **Burner Phone Item** — Players use a trap phone item to start deals and manage contacts.
* **Configurable Drug List** — Set which items can be sold, at what prices, and in which zones.
* **Dispatch Alerts** — Police jobs can be alerted when deals go wrong or heat gets too high.
* **Inventory Setup Included** — Ready-made item blocks for ox_inventory, qb-inventory, and more.
* **Bridge Compatible** — Uses FS Bridge for framework, target, and notification hooks.
